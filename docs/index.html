MacMute

One global shortcut. Teams presses its own mute button — from any window, with no third-party API.

Download for macOS View on GitHub

macOS 13 or later · Apple silicon · free and open source

The whole app: a menu bar icon that mirrors what Teams thinks, and one shortcut to flip it.

How it works

Two paths, picked automatically, so the shortcut always does something sensible.

In a Teams meeting

Presses the real Teams button

MacMute drives the actual “Mute mic” control through the macOS Accessibility API — about 0.2 ms. Teams performs its own action, so its window updates instantly and everyone in the meeting sees the right state.

No meeting

Mutes the input device

Falls back to CoreAudio on the default input device, which covers Zoom, Google Meet and Slack huddles. Those apps are genuinely muted, though their own UI will not show it.

Never drifts

Reads the state back

The menu bar icon is driven by the Teams button’s own label, so it stays correct even when you mute by clicking inside Teams.

Works when the API is off

No third-party Teams API

Nothing to enable, nothing your IT admin can switch off. If Teams runs, the shortcut works.

Install

  1. Download the .dmg from the latest release and drag MacMute into Applications.
  2. First launch: right-click the app → Open. MacMute is ad-hoc signed and not notarised, so a plain double-click is blocked by Gatekeeper.
  3. Grant System Settings › Privacy & Security › Accessibility, then press your shortcut from anywhere.

Upgrading? The ad-hoc signature changes on every build, so macOS treats a new build as a new app. Remove the old MacMute entry under Accessibility and add the new one. A paid Apple Developer ID would make the approval stick.

Build from source

Swift Package Manager, no dependencies. Xcode command line tools are enough.

git clone https://github.com/TuanBT/MacMute.git
cd MacMute

./build.sh                       # builds dist/MacMute.app
./package-dmg.sh                 # dist/MacMute-<version>-<build>.dmg
./ReleaseUtils/build_release.sh  # full release: icon, app, .dmg, .zip, .pkg

Version lives in VERSION, build number in BUILD; both show up in the menu, so you can always tell which build is installed. Pushing a v* tag builds and publishes a release from GitHub Actions.

Requirements

macOS13 (Ventura) or later
PermissionAccessibility — required for the Teams path. Without it, MacMute still mutes the input device.
TeamsOptional. No meeting means the CoreAudio fallback handles it.
